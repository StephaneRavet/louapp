# Changements de Rôles

Voici les modifications apportées aux rôles classiques du Loup-Garou :

| Rôle Classique | Nouveau Rôle |
|----------------|--------------|
| Voyante       | Espion       |
| Sorcière      | Médecin      |
| Garde         | Protecteur   |
| Indépendant   | Agent        |
| Multi         | Joker        |
| Cupidon       | Marieur      |
